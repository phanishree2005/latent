# India's Got Latent Official Merch Clone 🎭

An authentic recreation of the **[merch.samayraina.co](https://merch.samayraina.co/)** streetwear e-commerce experience.

![India's Got Latent Merch](public/images/logo.svg)

## ⚡ Features

- **WebGL 2.0 Red Velvet Curtain Transition**: Custom GLSL shader with 3D simplex noise folds, sheen, stage lighting, and theatrical center-parting reveal.
- **3D Interactive Talisman Installation**: Embedded Three.js hanging Nimbu-Mirchi (`chili-lime.glb`) with Verlet physics, gravity, natural pendulum sway, and pointer drag & swing physics.
- **Dual Crossing Crime Tape Tickers**: Diagonal `-2.5°` and `+2.5°` yellow caution tapes with infinite marquee animations (`LOREM IPSUM • LAURA LASUN`).
- **Dynamic 27-Product Streetwear Catalog**: Extracted from official inventory with oversized tees, acid-wash tops, tote bags, balaclava masks, and bobble heads.
- **Video Previews on Product Cards**: Hovering or clicking the gold `[ ▶ ]` button streams model preview video clips directly in the card.
- **Interactive Cart Drawer**: Free shipping threshold progress bar (over ₹499), promo code validation (`LATENT10`, `RHINO20`), and audio chime feedback.
- **"KYA BOLTI PUBLIC?" Testimonials**: Interactive quote book with celebrity reactions (Sharon Verma, Rakhi Sawant, Samay's Lawyer, etc.).
- **"REVISION KAR LO" Episodes Archive**: Season 2 episode highlights with modal video player.
- **Full Legal & Support Routes**: `/products`, `/terms`, `/returns`, and `/contact`.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **3D & Shaders**: Three.js, WebGL 2.0 (GLSL), GLTFLoader
- **Sound**: Web Audio API Synthesizer
- **Icons**: Lucide React
- **Typography**: Anton & Special Gothic

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/phanishree2005/latent.git

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## 📦 Production Build

```bash
npm run build
npm run start
```
